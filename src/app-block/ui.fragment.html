Export privacy, limits, and standalone version

Editing stays in this browser. Saving passes the finished file and its retained metadata, including prompts and workflows, to Civitai's page in this tab so it can download it. That page can access the entire export. The reviewed download path does not upload it; future host behavior is outside this editor's control.

Files up to 50 MiB save directly. Larger files use an explicitly approved lossless ZIP within 256 MiB including overhead. Batches may need several ZIPs. Original pixels and animation frames are preserved. Keep this tab open until your downloads are checked.

Use standalone for oversized files or if you do not want exports to reach Civitai's page. To continue edits, open the exact original images in the locally built standalone editor, then choose Resume edits with a saved edit handoff. The published GitHub version may need this new feature before it can import a handoff.

Only public resource identities are cached, in bounded memory for this tab. Refreshing or closing clears the cache and unsaved edits. No credentials are saved.

Choose images to inspect their export size. Save edit handoffs separately before closing this tab.
