# Code of conduct

Treat people with respect across issues, pull requests, discussions, and other project spaces. Welcome beginner questions and people with different levels of experience. Give specific feedback about the work and use evidence when you disagree.

Harassment, threats, personal attacks, and posting other people’s private information violate this standard. Maintainers may remove harmful material, close conversations, and restrict participation to protect the community. GitHub’s reporting tools are available when you need to report harassment or other abuse privately. [Report abuse or spam on GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)

For a software vulnerability or a suspected data leak, use the project’s private vulnerability channel. [Security policy](SECURITY.md)
