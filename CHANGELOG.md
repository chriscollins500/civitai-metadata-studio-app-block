# Changelog

## 0.1.1

Civitai deployed this version to civitai.com and civitai.red on November 23, 2026. This tag is the first public source snapshot of that hosted release.

- Read and edit generation metadata in PNG, JPEG, WebP, and supported animations.
- Verify exact Civitai model identities and examine evidence when claims disagree.
- Save lossless copies with an explicit disclosure before the finished file is passed to Civitai’s page.
- Use a direct download for ordinary output and lossless ZIP downloads for larger files and batches.
- Respect the current host’s public catalog rules. Both listings use Civitai’s `pg13` app-surface rating.
- Reproduce the deployed HTML and archived package from the committed source and build epoch.
