# Support

## Using the hosted app

Try the [website guide](https://chriscollins500.github.io/civitai-metadata-studio-app-block/guide/) and the [troubleshooting table](docs/Troubleshooting.md). For questions about editing and exports, share the host and what you were trying to do in [Discussions](https://github.com/chriscollins500/civitai-metadata-studio-app-block/discussions).

For a reproducible hosted problem, use the App Block issue form. Include the Civitai domain, browser, file type, steps, and exact error message. A tiny synthetic example helps test a fix. [Open an issue](https://github.com/chriscollins500/civitai-metadata-studio-app-block/issues/new/choose)

For a broken link, confusing instructions, or a website accessibility problem, use the website or docs form. Identify the page and the part that needs attention. [Report a website or docs issue](https://github.com/chriscollins500/civitai-metadata-studio-app-block/issues/new?template=website-or-docs.yml)

## Using standalone

The standalone edition has its own downloads, wiki, and support. Use these links for the portable HTML and optional automation.
